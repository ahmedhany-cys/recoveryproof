2. Incident description

At 07:40 UTC an attacker phishes the backup administrator and gains the 'backup-admin' role. That role can bypass governance-mode retention on the primary vault. The attacker deletes the two newest ERP recovery points, then tries and fails to delete a database copy in the isolated vault. The intrusion is detected at 09:00. No production system is down yet, but leadership must know which systems would still be recoverable if the attacker followed up with ransomware.
